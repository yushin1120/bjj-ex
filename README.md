## 🚀 GitHub Pages 배포 활성화 방법

1. GitHub 레포지토리 접속: [https://github.com/yushin1120/bjj-ex](https://github.com/yushin1120/bjj-ex)
2. **Settings** 탭 > **Pages** 메뉴 이동
3. **Build and deployment** 항목의 **Source**를 `Deploy from a branch`로 설정
4. **Branch**를 `main` 및 `/(root)` 로 선택 후 **Save** 클릭
5. 1~2분 후 위의 라이브 URL로 전 세계 어디서나 접속 가능합니다!

## 🚀 GoJob (고잡) : 직업찾기 테스트

12가지 인터랙티브 상황 문답과 심리학 RIASEC 모델을 기반으로 최적의 천직 TOP 3와 직무 역량을 도출하는 직업 적성 테스트 웹 애플리케이션입니다.

- **접속 경로**: [./job-test/index.html](./job-test/index.html)
- **주요 기능**:
  - **12문항 심리/적성 진단**: 역할 분담, 난관 해결, 라이프스타일 가치 등 몰입감 있는 롤플레잉 선택지
  - **16가지 직무 페르소나 매칭**: 하이테크 아키텍트, 딥테크 사이언티스트, 인터랙션 아티스트, 그로스 마케터 등
  - **HTML5 Canvas 6각 레이더 차트**: R(현실), I(탐구), A(예술), S(사회), E(진취), C(체계) 역량 밸런스 시각화
  - **추천 직업 TOP 3**: 직무 설명, 요구 역량 스킬 칩, 미래 산업 트렌드 태그 제공
  - **업무 케미 궁합 분석**: 환상의 꿀케미 vs 주의할 케미 분석
  - **결과 카드 이미지 저장 & 공유**: Canvas 기반 고해상도 결과 카드 즉시 이미지 다운로드 및 URL 복사
  - **16대 직무 도감 둘러보기**: 전체 직무 페르소나를 한눈에 볼 수 있는 인터랙티브 모달 지원
