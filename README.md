## 🚀 GitHub Pages 배포 활성화 방법

1. GitHub 레포지토리 접속: [https://github.com/yushin1120/bjj-ex](https://github.com/yushin1120/bjj-ex)
2. **Settings** 탭 > **Pages** 메뉴 이동
3. **Build and deployment** 항목의 **Source**를 `Deploy from a branch`로 설정
4. **Branch**를 `main` 및 `/(root)` 로 선택 후 **Save** 클릭
5. 1~2분 후 위의 라이브 URL로 전 세계 어디서나 접속 가능합니다!

## 🎮 주요 기능

- **🥋 32가지 주짓수 커리큘럼**: 벨트별(화이트~블랙) 기술 순서 맞추기 퀴즈 및 승급 심사
- **🏢 체육관 경영 시스템**: 수련생 모집, 시설 업그레이드, 체육관 일일 보고서
- **🐯 캐릭터 시스템**: 캐릭터 레벨업, 경험치 획득 및 칭호 시스템
- **📱 PWA & 데스크톱 앱 지원**: 모바일 웹 설치 및 Electron 기반 데스크톱 실행 지원
